# Evaluacion Parcial 1 - Fullstack 2
Proyecto: Ferreteria Los Maestros

Entrega correspondiente a la primera evaluacion parcial del ramo Fullstack II (Duoc UC).
Consiste en la maqueta y funcionamiento basico de una tienda online de materiales y herramientas, junto con su panel administrativo.

### Tecnologias usadas
- HTML5 para la estructura de las paginas
- CSS y Bootstrap para el diseño responsive
- JavaScript para validaciones de formularios y logica basica
- Imagenes y logo creados con Inteligencia Artificial

### Contenido del proyecto
- Vistas de la tienda (inicio, productos, detalle, carrito, contacto, nosotros, blog, login y registro)
- Panel de administracion (gestion de productos y usuarios)
- Presentacion en PPT con la explicacion del proyecto
